# Pace ⏱️

Pace 是一款**本地优先 (Local-First)** 的个人任务与节奏管理应用。基于「少即是多」的理念，Pace 将相对碎片和焦虑的事务管理缩减为最纯粹的**今日专注**与**时间流复盘**，并确保你的所有数据始终极度安全地保存在你的设备本地。

## ✨ 核心特性

* **🏠 纯粹的「今天」看板**：每天的精力都是有限的，Pace 鼓励你只把今天确切要做的任务排入视线。动态的专注引擎会根据你正在运行的任务，实时推算你今天的「预计收尾时间」和「今日动态总用时」。最近 7 日的状态达成缩影长条（WeeklyStrip）会赋予你强烈的正向节奏反馈。
* **📭 零压力的「收集箱」**：随时捕获脑海中一闪而过的待办记录，等有余力时，再将它们一键排入某一天的执行流中。支持对未起步草稿记录的无损安全物理删除。
* **⏱️ 独占式专注底层记录**：严密的防误触引擎——同一时间只会有一个任务处于运行状态（Running）。智能排他逻辑会确保你在跨任务弹跳和切换时自动处理上一个任务的结算与挂起，帮你找回节奏。
* **📊 深度时间洞察 (Insights)**：基于 Recharts 构建了支持「日/周/月/年」全局作用域一键切换的图文宏观看板。支持生成类似 GitHub 风格的长周期热力贡献图、展示多类型耗时占比的环形图，并提供针对烂尾逾期工程的单独警示名录。同时为「今日/昨日」提供了精致的**全自动化专注微流 (Micro-Timeline)**，通过支持光标联动的视差放大与横向动态变焦轴，将你单日的真实执行切片完美还原为呼吸组件。
* **🛡️ 智能时间缓冲 (Smart Buffer)**：内置标签聚类分析器。能通过计算识别出你极易“低估耗时”的类型任务。下次创建该类标签任务时，系统会自动在底部悬浮防抖预警，给出建议预留宽限时间的具体数值，帮你重塑时间直觉。
* **⚡ 极速起步体验**：在屏幕右下角集成全局“动作枢纽 (Speed Dial)”，支持随时呼出手填、拍照及相册交互界面。内嵌基于 Web Crypto API (AES-GCM) 强加密的腾讯云高精度 OCR 引擎与原生图像拖拽裁剪组件，结合强大的树状自然语义解析器（不仅支持多行批量录入，更能智能清洗 `✓`、`✅` 等完成态脏字符并自动打上【校内完成】标签），提供真正“点开即拍、框选即得”的免手打极速多行体验，并全自动向下继承分发科目组与全局附加标签。
* **🎨 个性化陪伴与资料**：内置支持 1:1 圆形比例裁切的本地头像裁剪器 (`AvatarCropper`)。用户昵称与基于 WebP Base64 压缩过滤的头像流会无缝融入在主界面的侧边栏及任务开启时的沉浸式深呼吸转场幕布中，提供极致的情感化与拟人化关怀感。
* **🎯 沉浸式工作台与随时复盘 (Focus & Retro)**：引入独立的全屏侧滑抽屉 `TaskDetailWorkbench`。该工作台支持在左半区提供巨型视觉原子钟，右半区展示任务专属的 Markdown 指引素材及自动匹配提取的流媒体视窗（支持同屏并行解析至多 3 组富媒体：Bilibili / YouTube / Vimeo / 小红书 / 知乎 / 抖音 等多平台链接与组件挂载）。当任务完成时，它会引导你写下针对性的经验总结和成绩反馈；即便任务完结也能随时被标记原因后“强制重启”。
* **🔁 习惯引流与零追债法则 (Habits & Zero-Debt)**：专属的模板化日常习惯管理体系。提供一键式的状态归档与彻底删除控制，将「生命周期」交还给用户。每天首次启程时，系统会隐式比对你的作息模板（按周/按月），自动将今日该达标的习惯投放到看板中。坚决执行零追债红线：系统通过心跳检测，凡到达每晚 22:00 的“晚安期”，一切尚未完成的待办与习惯都会无差别强制标记为过期或跳过，确保次日从不背负沉重的历史债务。它还附带专门的漏卡统计与执行稳定性洞察面板。
* **🏔️ 长线目标与进度管理 (Goals & Sessions)**：针对需数天或数周完成的大型项目，提供独立的「目标」管理域。通过认知拆解，鼓励将庞大的“假定压力”解构成可单日执行的微小“片段 (Session)”。自带燃尽图预警和双轨进度追踪机制；专属的“评论区”形式支持互动反馈或执行日记，让长期负重前行的旅途拥有可视化的阶段性里程碑反馈。
* **☁️ 渐进式云端接管 (Cloud Sync & CS Architecture)**：[🆕 Sprint 14] 保留纯正的 Local-First 基因。在自愿开启云端账号后，系统底层的增量同步引擎 (SyncService) 会静默收集 IndexedDB 的所有增删改动作，于暗地安全推流至 Prisma 持久化层。具备严禁数据互相污染的双步接管逻辑 (Two-Step Session Commitment) 以及严格的防抖失败重试机制，提供极客级安全的离线/在线混合体验。
* **📁 自带媒体分发与云端图床 (OSS Media Storage)**：彻底重构 Markdown 引擎支持多媒体能力。底层完全兼容以 AWS S3 协议为主流的任意对象存储（包含 Cloudflare R2、七牛云等），采用极致轻量的“预签名 URL 直传”跳板设计。编辑框提供原生级顺滑的文件拖拽、截图剪贴板自动监听，自带分级式的严格配额拦截底座及坚固的前端状态防御拦截。独家的高自适应能力，能够精准嗅探直传的 MP4/MOV 视频文件并在正文极速渲染成为内嵌的 HTML5 播放器。
* **🌐 全栈游览审计与追踪系统 (Telemetry & Analytics)**：[🆕 Sprint 15] 专门为跨终端协同搭建的宏观防刷雷达。内置了专门监听匿名游览生命周期的路由探针 (`VisitorTracker`) 与针对登录态设备的 UA 指纹 / IP 采集引擎。所有安全事件与数据流向均建立在完备的法律合规 (Privacy Policy) 与强阻断网关上。支持在精细化解耦后的多路由独立超管大盘 (`/admin`) 中渲染详细的每日总设备请求数 ( PV/UV Dashboard) 与个人数字资产存量快照。
* **🛡️ 全局安全门控与双向工单 (Security Gateway & Tickets)**：[🆕 Sprint 16] 为公测与内测管理提供了基于超级管理员环境变量白名单 (`SUPER_ADMIN_EMAILS`) 与云端远程总阀 (`GLOBAL_LOGIN_ENABLED`) 的一键熔断网关机制，在“熔断期”内实时物理拦截未授权的公开登录发信。同时，首创内嵌了无感接管体验的多图意见反馈双向对讲工单大板，打通基于 S3/OSS 无痕安全直传（独立 `feedbacks` 层）与动态前置配额防控体系。配有防裁切全屏级的光箱看图 (Lightbox) 效果，以及由超管独立操控且状态即时映射的自动化流水线管理大盘。
* **🔒 绝对的本地隐私**：采用 Dexie.js (IndexedDB) 构建底层存储，即便不注册账号，所有核心任务数据与执行碎片均永久落盘、加密脱敏在你自己的浏览器里。支持配置页一键导出/导入 JSON 进行手动冷备份。

## 🛠️ 技术栈

* **前端框架**：Next.js (App Router)
* **语言规范**：TypeScript
* **UI 与审美系统**：Tailwind CSS + shadcn/ui + Lucide Icons
* **本地化数据库**：Dexie.js (IndexedDB)
* **测试与断言**：Vitest

## 🚀 本地开发快速开始

```bash
# 1. 下载代码并安装依赖包
npm install

# 2. 启动基础所需服务 (PostgreSQL / Redis)
docker-compose up -d

# 3. 配置开发环境变量与数据库同步
cp .env.example .env.development
npx prisma generate
npx prisma db push

# 4. 启动本地开发服务器
npm run dev
# 访问 http://localhost:3000 打卡进入
```

## 🌍 线上生产环境部署

要在全新的云服务器（如 Ubuntu / CentOS）上部署发布版，请严格按照以下 “四步走” 标准基线操作：

```bash
# ==========================================
# 第一步：准备环境与后台守护支撑
# ==========================================
# 1. 拉取远端仓库代码
git pull origin main

# 2. 准备生产环境配置（⚠️ 关键坑位回避）
# 请将实际秘钥写入配置，并务必重命名为 `.env`。
# 如果使用 .env.production 文件，由于 Prisma 底层工具库限制，会导致其脱序无法读取数据库链接
# 推荐指令：
# cp .env.example .env
# nano .env （完成所需秘钥配置）

# 3. 后台独立启动基础支撑组件（如果线上机器使用了本项目自带的 docker-compose）
# 这将同时唤醒 Redis 内存队列与云端 PostgreSQL 数据库（如果您没有使用外部 RDS 云数据库的话）
docker-compose up -d

# ==========================================
# 第二步：安装与数据库强制同步
# ==========================================
# 安装 Node 生产依赖
npm install 

# 生成 Prisma 客户端类型映射
npx prisma generate

# 【核心必做】将最新的数据模型覆盖到远端 PG 数据库中建表
npx prisma db push 

# ==========================================
# 第三步：生产模式封包构建
# ==========================================
npm run build

# ==========================================
# 第四步：守护态后台常驻服务
# ==========================================
# 全局安装守护进程工具 PM2
npm install pm2 -g

# 以生产强守卫模式挂载服务，并命名为 pace-app
pm2 start npm --name "pace-app" -- run start

# 常用运维指令
# pm2 logs pace-app (查看崩溃和打印日志)
# pm2 restart pace-app (重启)
```
