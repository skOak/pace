# Pace 产品进阶计划 - Sprint 9 & 10 (深度属性与习惯系统)

## 1. 产品核心原则 (First Principles)
* **专注力隔离：** 外部学习资源（如视频）必须在应用内嵌入播放，严禁跳转至外部网站，以杜绝算法推荐和社交评论的干扰。
* **动态对齐：** 承认计划的易变性。允许在任务任何阶段（待办、执行中）修改属性，但需记录初始预估值以供后期偏差分析。
* **习惯锚点：** 重复性任务是建立节奏感的基石。通过“习惯模板”自动生成每日任务，减少手动录入的认知负担。

---

## 2. Sprint 9: 任务详情与沉浸式内容 (Rich Context)

### 2.1 任务详情页 (Task Detail View)
* **沉浸式设计：** 为每个任务提供全屏/半屏工作台。
* **Markdown 渲染：** 支持文本指引、图片说明、任务清单。
* **视频嵌入播放 (In-App Player)：** * 自动识别描述中的 Bilibili 或 YouTube 链接。
    * **强制嵌入：** 将链接转化为 `<iframe>` 播放器，禁止跳转至外部网站。

### 2.2 全状态编辑 (Universal Editor)
* **实时修改：** 在「收集箱」、「今天」或「执行中」均可修改任务所有属性。
* **数据快照：** 第一次修改预估时长时，原值自动备份至 `initial_estimated_duration`。
* **认知属性：** 增加 1-3 级难度星级（Difficulty）及自信度（Confidence: 🤔/😎）标记。

---

## 3. Sprint 10: 习惯系统与冷启动逻辑 (Habits & Feedback)

### 3.1 习惯管理 (Habit Tab)
* **功能描述：** 独立 TAB 页面，管理“习惯模板”。模板不直接计时，仅作为生成任务的母版。
* **状态切换：** 模板可设为“激活”或“暂停”。

### 3.2 自动生成逻辑 (Bootstrap Sync)
* **业务逻辑：** 应用每次启动时检查 `last_habit_sync_date`。
* **同步动作：** 若检测到跨日，系统遍历所有活跃模板，根据频率规则为“今天”生成对应的任务实例。

### 3.3 任务重开与反馈
* **重开机制：** 允许 Completed 任务重开。重开时需选择/输入原因（如：需要修改、老师要求返工）。
* **收尾评价：** 任务结束时允许记录简短反馈（家长点评或自我总结）。

### 3.4 习惯生命周期与逻辑规约 (Lifecycle Logic)
* **状态定义：**
    * `Active`: 每日按规约生成任务。
    * `Paused`: 停止生成任务，保留历史数据。
    * `Deleted`: 仅限从未生成过任务的习惯；若已有历史数据，则自动转为 `Archived`（保留数据，置灰和已完成任务一样，不可编辑）。
* **任务失效机制：**
    * **零追债原则：** 和「今天」任务会自动过期一样，在同样的时间点，所有未完成的习惯任务统一标记为 `Expired`，**严禁**自动滚入第二天。
    * **补救措施：** 若某项习惯任务极其重要且必须完成，用户需在「今天」手动重新创建，系统记录为“计划外增量”。

### 3.5 习惯属性与编辑影响 (Attribute Sync)
* **模板属性：** 习惯模板拥有与 Task 完全一致的属性（标题、时长、Markdown 详情、视频链接、难度、自信度）。
* **编辑策略：** * 修改模板仅影响**未来生成**的任务实例（Future-facing）。
    * 已生成的「今天」任务不受模板修改影响，需独立编辑。
* **统计与反馈 (Habit Retrospective)：**
    * **节奏稳定性：** 统计该习惯启动时间的标准差。
    * **预估进化论：** 展示该习惯“预估时长 vs 实际时长”随时间变化的收敛曲线。
    * **漏卡分析：** 记录失效任务，并支持在复盘时标注“因外部干扰跳过”或“主动放弃”。

## 4. UI 布局规划 (UI Layouts)

### 4.1 任务详情页 (Task Detail Page)
建议采用 **左右分栏布局**：
* **左侧 (Focus Zone)：** 巨大的环形计时器（颜色随状态流转）、标题、难度星级、暂停/完成按钮。
* **右侧 (Content Zone)：** * **顶部：** 16:9 嵌入式视频播放窗口。
    * **中部：** Markdown 滚动区域。
    * **底部：** 编辑属性入口、历史备注/留言记录。



### 4.2 习惯规则选择器 (Recurring Rule Selector)
* **核心组件：水平星期排布 (Weekly Row)**
    * 一排 7 个圆型按钮（一、二...日）。
    * 选中态：Pace 专注蓝；未选中态：浅灰色底。
* **预设快捷键 (Quick Presets)：**
    * **[每天]**：一键全选。
    * **[上学日]**：自动勾选 周一至周五。
    * **[周末]**：自动勾选 周六、周日。
* **每月重复 (Monthly Logic)：** 切换至月度模式后，展示 1-31 的数字网格。
* **摘要：** 底部实时显示一行文字：“每逢 [周一, 周三] 自动在‘今天’生成任务”。

### 4.3 习惯列表展示逻辑 (Habit List View)
为了让小朋友直观感知长期负荷，习惯列表需体现“今日状态”：
* **状态标签 (Status Badges)：**
    * **「已排期」**：该习惯符合今日规则，且任务已生成到“今天”列表。
    * **「休息日」**：根据规则，该习惯今天不执行（如周末的课外作业）。
    * **「已暂停」**：习惯模板被手动关闭。
* **交互操作：**
    * **一键加入今天**：对于“休息日”的习惯，允许点击按钮临时为今天生成一个实例。
    * **今日跳过**：对于“已排期”的习惯，允许点击跳过，从而从“今天”清单中移除该实例。

## 5. 数据库 Schema 变更建议 (For Agent Reference)

### Tasks 表新增字段：
* `description`: String (Markdown 源码)
* `difficulty`: Integer (1, 2, 3)
* `confidence`: Boolean (True/False)
* `initial_estimated_duration`: Integer (原始预估)
* `comments`: String (复盘笔记)
* `template_id`: String (关联习惯母版 ID)

### 新增 HabitTemplates 表：
* `id`: UUID
* `title`: String
* `estimated_duration`: Integer
* `tags`: Array
* `frequency_type`: String (Weekly / Monthly)
* `frequency_rule`: Array (如 [1, 3, 5] 代表周一三五)
* `is_active`: Boolean
* `created_at`: Timestamp

### LocalStorage 记录：
* `last_habit_sync_date`: String (格式：YYYY-MM-DD)
