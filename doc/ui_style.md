# Pace UI 设计规范 (v1.0) - "找到你的节奏"

## 1. 全局设计系统 (Global Design System)
**核心理念：** 呼吸感、确定性、低认知摩擦。

### 1.1 配色方案 (Color Tokens)
| 角色 | 颜色代码 | 心理暗示 |
| :--- | :--- | :--- |
| **主色 (Focus)** | `#4A90E2` (专注蓝) | 沉稳、清爽，用于执行中状态 |
| **成功 (Success)** | `#50E3C2` (成长绿) | 达成、正向反馈，用于已完成 |
| **警告 (Warning)** | `#FFAB40` (柔和橙) | 提醒、非侵入性，用于超时或过期 |
| **背景 (Background)** | `#F8F9FA` (极简灰) | 留白、消除杂讯 |
| **文字 (Text)** | `#2C3E50` (深蓝灰) | 高对比度，易读性 |

### 1.2 视觉样式 (Visual Style)
* **圆角 (Radius)：** 全局采用 `24px` 或更大的圆角（Squircle），消除尖锐感。
* **阴影 (Shadow)：** 极轻微的弥散阴影 `0 4px 20px rgba(0,0,0,0.05)`，营造卡片悬浮感。
* **字体 (Typography)：** 优先使用圆润的无衬线体（如 *Rounded Sans*），正文字号保持在 `16px-18px`，重点数字加粗放大。

## 2. 核心页面布局 (Page Layouts)

### 2.1 「今天 (Today)」：当前步调看板
**目标：只看当下，消除焦虑。**

* **顶部 - 能量锚点 (Anchors)：**
  * 左侧：☀️ **启动锚点** (显示今日首个任务开始时间)。
  * 右侧：🌙 **收尾预警** (根据当前 Pace 动态计算的预计结束时间)。
* **中部 - 脉冲计时器 (The Pulse)：**
  * **环形双轨进度：** 外圈虚线（预估时长），内圈实线（实际耗时）。
  * **呼吸效：** 运行中内圈实线伴随轻微缩放动画，赋予时间“生命感”。
* **下部 - 任务流 (The Flow)：**
  * 垂直卡片列表，当前任务处于置顶放大状态。
  * **Spark Reward：** 符合闪电启动条件时，首张卡片带有金色微光特效。

### 2.2 「收集箱 (Inbox)」：快速捕捉
**目标：零压力录入。**

* **视觉：** 模拟叠放的便签纸。
* **OCR 交互：** 点击底部 📷，进入全屏扫描模式。
* **气泡化结果：** 识别出的文本以“可点击气泡”形式悬浮，点击即可确认转为任务。
* **滑动手势：** 右滑“排入今日”，左滑“暂存/删除”。

### 2.3 「周/月 (Horizon)」：宏观节奏
**目标：建立长期的心理预期。**

* **周视图：** 横向滚动的日柱图，柱体高度 = 预估总负荷，颜色深浅 = 完成度。
* **月视图：** 极简 Heatmap，深绿（全达成）、淡橙（有过期）。点击日期下探显示当日“时间线轨迹”。

### 2.4 「洞察 (Insights)」：自我进阶镜
**目标：成就感驱动。**

* **足迹图 (Pace Tracks)：** 平行的双轨线条，对比“计划轨迹”与“真实轨迹”。
* **能量波 (Energy Wave)：** 统计一周启动时间的一致性，曲线越平滑，勋章越亮。
* **标签气泡：** 统计不同 Tag（#数学、#阅读）的时间占比，气泡大小代表投入程度。

## 3. 关键交互逻辑 (Key Interactions)

### 3.1 “确认成本”弹窗 (Soft Guard)
* **场景：** 任务切换。
* **设计：** 底部弹出半屏 Action Sheet。
* **内容：** “当前 [数学] 已完成 70%，确认要中断吗？”
* **策略：** 将“继续专注”按钮设计得更易点击，将“确定切换”设计为次要样式。

### 3.2 强制“降速”仪式
* **场景：** 点击“开始新任务”后。
* **效果：** 屏幕短暂变暗 0.5 秒，显示：“深呼吸，准备好开始 [任务名] 了吗？”。
* **目的：** 心理卸载上一个任务，进入新的专注状态。

### 3.3 温柔超时提醒
* **场景：** 实际用时 > 预估用时。
* **效果：** 计时器背景平滑过渡为浅粉色，出现 ⏳ 图标，不报错，不中断，仅记录。

## 4. 响应式与组件规范 (Web Component)

* **分栏架构：** 桌面端左侧菜单（300px），中间主看板（700px），右侧挂件栏（300px）。
* **计时器组件：** 支持一键最小化为右下角的“悬浮球”，即使在浏览其他页面时也能看到进度流逝。
