# Pace 开发计划 - Sprint 17: 发布冲刺与环境稳固

## 1. 产品核心原则 (First Principles)
* **环境确定性：** 严格隔离开发与生产环境，确保“代码一致，配置分离”，杜绝生产环境泄露密钥。
* **身份去摩擦：** 放弃复杂的短信审核，通过自建域名邮件（Resend/SMTP2GO）提供低成本、高可靠的身份校验。
* **数据韧性：** 上线前必须具备自动化的数据备份方案，不能把用户的信任全部寄托在单一磁盘上。

---

## 2. 功能清单 (Task List)

### 2.1 环境配置校验 (Env Isolation)
* **.env 分离：** 校验并完善 `.env.development` 和 `.env.production`。
* **敏感项检查：** 确保生产环境的数据库连接串、OSS Key、OCR Key、邮件 Token 全部指向正式账号。
* **Git 安全：** 确认 `.gitignore` 已包含所有 `.env*` 文件，严防私钥入库。

### 2.2 邮件登录体系迁移 (Email Auth)
* **身份切换：** UI 及后端逻辑全面从“手机号+验证码”切换为“邮箱+验证码”。
* **双通道推送 (Failover)：**
    * **主通道：** 接入 Resend (resend.com)，利用 API 高效发送。
    * **备选通道：** 配置 SMTP2GO，当 Resend 调用失败或达到配额时，自动降级切换。
* **域名校验：** 在邮件服务商处完成 SPF、DKIM、DMARC 记录配置，确保邮件不进垃圾箱。

### 2.3 安全与反爬校验 (Bot Protection)
* **Cloudflare 正式版：** 将 Turnstile (人机校验) 的 Site Key 和 Secret Key 替换为正式环境版本，并完成域名白名单配置。
* **接口限流 (Rate Limit)：** 在后端为邮件发送接口增加频率限制（如：同一 IP/邮箱 60秒内只能发送一次），防止邮件账户被刷爆。

### 2.4 数据运维准备 (Ops - 补充项)
* **数据库自动备份：** 编写一个简单的 Cron 脚本，每日将 PostgreSQL 数据 dump 并上传至另一个独立的存储空间（如你的 S3 备份目录）。
* **CORS 策略收紧：** 正式环境中，后端的跨域配置必须严格限定在你的正式域名下，拒绝来自 localhost 或其他域名的请求。
* **健康检查 (Health Check)：** 增加一个 `/api/health` 接口，用于监控数据库、OSS、邮件服务的联通状态。

### 2.5 合规与辅助页面 (Legal - 补充项)
* **隐私协议与条款 (Privacy/TOS)：** 在「指南」页或登录页下方增加简单的隐私政策，说明数据是如何存储和加密的。
* **自定义错误页：** 确保生产环境下的 404 和 500 页面不会暴露后端调用堆栈信息。
